# Magnetrip Phase 1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the shared substrate both apps depend on — the design-token pipeline (one `tokens.json` → web CSS variables + a Flutter theme file), the shared API DTO contracts + validation, the Supabase client factories, the database schema + RLS + storage + public-read function, and a `CLAUDE.md` for each app.

**Architecture:** `magnetrip-web` owns everything shared. A Node generator turns `design/tokens.json` into (a) web CSS variables consumed by Tailwind v4 / shadcn and (b) a self-contained Dart theme written into `magnetrip/lib/theme/`. TypeScript DTOs + Zod schemas define the API contract. Supabase schema uses Row-Level Security so a user-scoped client can only touch its owner's rows; anonymous visitors reach public trip data only through a `SECURITY DEFINER` function.

**Tech Stack:** Next.js 16 / React 19 / TypeScript (strict), Tailwind v4 + shadcn/ui, Vitest, Zod, `@supabase/ssr` + `@supabase/supabase-js`, Supabase Postgres/Storage/RLS, Flutter (Dart) theme output only (no Flutter toolchain needed this phase).

## Global Constraints

- Write **only** inside `magnetrip/` and `magnetrip-web/`. Never create files at the repo root.
- Both apps consume the HTTP API in `magnetrip-web/app/api/*`; **no page/component/screen imports `supabase-js` for data.** Only the service layer touches Supabase data. (Auth/session via the Supabase SDK is allowed.)
- TypeScript **strict mode** (already on in `tsconfig.json`).
- Package manager for the web app is **pnpm** (a `pnpm-lock.yaml` exists).
- Design values are fixed (from the spec): palette "Expedition", font **Plus Jakarta Sans**, spacing `4·8·12·16·24·32·48·64`, radius `sm 8 / md 12 / lg 16 / xl 20 / 2xl 24 / full 9999`, light theme only.
- Public base URL: `NEXT_PUBLIC_SITE_URL=https://magnetrip-web.vercel.app`; public trip URL is `${NEXT_PUBLIC_SITE_URL}/t/{public_id}`.
- Supabase env already in `magnetrip-web/.env`: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `NEXT_PUBLIC_SITE_URL`.
- Both repos are on branch `feat/magnetrip-mvp`. Commit after every task with a Conventional Commit message.
- **Supabase changes:** apply SQL via the Supabase MCP (`apply_migration` / `execute_sql`) if available in the session; otherwise paste the SQL file into the Supabase Dashboard → SQL Editor. Keep every migration as a checked-in `.sql` file regardless.

## File Structure

**magnetrip-web/**
- `design/tokens.json` — single source of truth for all design tokens.

- `lib/validation/trip.ts` — Zod schemas that produce those types.

- `lib/env.ts` — validated environment accessor.
- `lib/env.test.ts` — Vitest tests for env parsing.
- `lib/supabase/server.ts` — cookie-based server client (`@supabase/ssr`).
- `lib/supabase/user-client.ts` — bearer-token user-scoped client (for Flutter requests).
- `supabase/migrations/0001_schema.sql` — tables, indexes, `updated_at` trigger.
- `supabase/migrations/0002_rls_storage.sql` — RLS policies + storage bucket + storage policies.
- `supabase/migrations/0003_public_trip_fn.sql` — `get_public_trip` function + grant.
- `supabase/verify/*.sql` — verification queries used by the plan steps.
- `CLAUDE.md` — web app guide.

**magnetrip/** (Flutter)
- `lib/theme/app_theme.dart` — GENERATED by the web token script. Self-contained (`flutter/material` only).
- `CLAUDE.md` — Flutter app guide.

Create `magnetrip-web/scripts/generate-tokens.mjs`:
```js
import { readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { dirname, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';

const HERE = dirname(fileURLToPath(import.meta.url));
const WEB_ROOT = resolve(HERE, '..');
const TOKENS_PATH = resolve(WEB_ROOT, 'design/tokens.json');
const CSS_OUT = resolve(WEB_ROOT, 'app/tokens.generated.css');
const DART_OUT = resolve(WEB_ROOT, '../magnetrip/lib/theme/app_theme.dart');

export function loadTokens(path = TOKENS_PATH) {
  return JSON.parse(readFileSync(path, 'utf8'));
}

export function buildCss(t) {
  const c = t.color;
  const root = {
    '--background': c.background,
    '--foreground': c.textPrimary,
    '--card': c.surface,
    '--card-foreground': c.textPrimary,
    '--popover': c.surface,
    '--popover-foreground': c.textPrimary,
    '--primary': c.primary,
    '--primary-foreground': c.primaryForeground,
    '--secondary': c.secondarySurface,
    '--secondary-foreground': c.secondary,
    '--muted': c.secondarySurface,
    '--muted-foreground': c.textSecondary,
    '--accent': c.secondarySurface,
    '--accent-foreground': c.textPrimary,
    '--destructive': c.error,
    '--destructive-foreground': c.errorForeground,
    '--border': c.border,
    '--input': c.border,
    '--ring': c.primary,
    '--brand-accent': c.accent,
    '--brand-accent-foreground': c.accentForeground,
    '--success': c.success,
    '--success-foreground': c.successForeground,
    '--success-surface': c.successSurface,
    '--warning': c.warning,
    '--warning-foreground': c.warningForeground,
    '--text-muted': c.textMuted,
    '--radius': t.radius.md,
  };
  const theme = [
    '--color-brand-accent: var(--brand-accent);',
    '--color-brand-accent-foreground: var(--brand-accent-foreground);',
    '--color-success: var(--success);',
    '--color-success-foreground: var(--success-foreground);',
    '--color-success-surface: var(--success-surface);',
    '--color-warning: var(--warning);',
    '--color-warning-foreground: var(--warning-foreground);',
    '--color-text-muted: var(--text-muted);',
  ].map((l) => '  ' + l).join('\n');
  const vars = Object.entries(root).map(([k, v]) => `  ${k}: ${v};`).join('\n');
  return `/* AUTO-GENERATED by scripts/generate-tokens.mjs — do not edit by hand. */\n@theme inline {\n${theme}\n}\n\n:root {\n${vars}\n}\n`;
}

export function buildDart(t) {
  const c = t.color;
  const argb = (hex) => '0xFF' + hex.replace('#', '').toUpperCase();
  const colorField = (name, hex) => `  static const Color ${name} = Color(${argb(hex)});`;
  const colors = [
    colorField('primary', c.primary),
    colorField('primaryForeground', c.primaryForeground),
    colorField('secondary', c.secondary),
    colorField('secondarySurface', c.secondarySurface),
    colorField('accent', c.accent),
    colorField('background', c.background),
    colorField('surface', c.surface),
    colorField('border', c.border),
    colorField('success', c.success),
    colorField('warning', c.warning),
    colorField('error', c.error),
    colorField('textPrimary', c.textPrimary),
    colorField('textSecondary', c.textSecondary),
    colorField('textMuted', c.textMuted),
    colorField('disabled', c.disabled),
  ].join('\n');
  const px = (v) => String(parseFloat(v));
  const spacing = Object.entries(t.spacing)
    .map(([k, v]) => `  static const double s${k} = ${px(v)};`).join('\n');
  const radii = Object.entries(t.radius)
    .map(([k, v]) => `  static const double ${k.replace('2xl', 'xxl')} = ${px(v)};`).join('\n');
  return `// AUTO-GENERATED by ../magnetrip-web/scripts/generate-tokens.mjs — do not edit by hand.
import 'package:flutter/material.dart';

class MagnetripColors {
  MagnetripColors._();
${colors}
}

class MagnetripSpacing {
  MagnetripSpacing._();
${spacing}
}

class MagnetripRadii {
  MagnetripRadii._();
${radii}
}

ThemeData buildMagnetripTheme() {
  final scheme = ColorScheme.fromSeed(
    seedColor: MagnetripColors.primary,
    primary: MagnetripColors.primary,
    surface: MagnetripColors.surface,
    error: MagnetripColors.error,
    brightness: Brightness.light,
  );
  return ThemeData(
    useMaterial3: true,
    colorScheme: scheme,
    scaffoldBackgroundColor: MagnetripColors.background,
    fontFamily: '${t.font.family}',
  );
}
`;
}

function main() {
  const t = loadTokens();
  writeFileSync(CSS_OUT, buildCss(t));
  mkdirSync(dirname(DART_OUT), { recursive: true });
  writeFileSync(DART_OUT, buildDart(t));
  console.log(`Wrote ${CSS_OUT}\nWrote ${DART_OUT}`);
}

if (import.meta.url === `file://${process.argv[1]}`) {
  main();
}
```

const currentYear = new Date().getFullYear();

export const createTripSchema = z.object({

  year: z.number().int().min(1800).max(currentYear + 1).optional(),

export const updateTripSchema = z.object({

  year: z.number().int().min(1800).max(currentYear + 1).nullable().optional(),

  coverImageId: z.string().uuid().nullable().optional(),
});

export const registerImageSchema = z.object({
  storagePath: z.string().min(1),
  position: z.number().int().min(0),
  width: z.number().int().positive().optional(),

});

export const reorderImagesSchema = z.object({

type RawEnv = Record<string, string | undefined>;

export interface PublicEnv {
  supabaseUrl: string;
  supabaseAnonKey: string;
  siteUrl: string;
}

export function parsePublicEnv(raw: RawEnv): PublicEnv {
  const require = (key: string): string => {
    const value = raw[key];
    if (!value) throw new Error(`Missing required environment variable: ${key}`);
    return value;
  };
  return {
    supabaseUrl: require('NEXT_PUBLIC_SUPABASE_URL'),
    supabaseAnonKey: require('NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY'),
    siteUrl: require('NEXT_PUBLIC_SITE_URL'),
  };
}

export function getPublicEnv(): PublicEnv {
  return parsePublicEnv({
    NEXT_PUBLIC_SUPABASE_URL: process.env.NEXT_PUBLIC_SUPABASE_URL,
    NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY: process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY,

-- Magnetrip Phase 1 — RLS + storage
alter table public.trips enable row level security;
alter table public.trip_images enable row level security;

-- trips: owner-only for all verbs
drop policy if exists trips_select_own on public.trips;
create policy trips_select_own on public.trips
  for select using (user_id = auth.uid());
drop policy if exists trips_insert_own on public.trips;
create policy trips_insert_own on public.trips
  for insert with check (user_id = auth.uid());
drop policy if exists trips_update_own on public.trips;
create policy trips_update_own on public.trips
  for update using (user_id = auth.uid()) with check (user_id = auth.uid());
drop policy if exists trips_delete_own on public.trips;
create policy trips_delete_own on public.trips
  for delete using (user_id = auth.uid());

-- trip_images: owner-only via the parent trip
drop policy if exists trip_images_select_own on public.trip_images;
create policy trip_images_select_own on public.trip_images
  for select using (exists (
    select 1 from public.trips t where t.id = trip_images.trip_id and t.user_id = auth.uid()));
drop policy if exists trip_images_insert_own on public.trip_images;
create policy trip_images_insert_own on public.trip_images
  for insert with check (exists (
    select 1 from public.trips t where t.id = trip_images.trip_id and t.user_id = auth.uid()));
drop policy if exists trip_images_delete_own on public.trip_images;
create policy trip_images_delete_own on public.trip_images
  for delete using (exists (
    select 1 from public.trips t where t.id = trip_images.trip_id and t.user_id = auth.uid()));

-- storage bucket: public read, owner-scoped writes ({user_id}/{trip_id}/file)
insert into storage.buckets (id, name, public)
  values ('trip-images', 'trip-images', true)
  on conflict (id) do update set public = true;

drop policy if exists trip_images_public_read on storage.objects;
create policy trip_images_public_read on storage.objects
  for select using (bucket_id = 'trip-images');

drop policy if exists trip_images_owner_write on storage.objects;
create policy trip_images_owner_write on storage.objects
  for insert to authenticated
  with check (bucket_id = 'trip-images' and (storage.foldername(name))[1] = auth.uid()::text);

drop policy if exists trip_images_owner_delete on storage.objects;
create policy trip_images_owner_delete on storage.objects
  for delete to authenticated
  using (bucket_id = 'trip-images' and (storage.foldername(name))[1] = auth.uid()::text);
```

-- Magnetrip Phase 1 — public read function (bypasses RLS, exposes only public fields)
create or replace function public.get_public_trip(p_public_id text)
returns json
language sql
security definer
set search_path = public
stable
as $$
  select case when t.id is null then null else json_build_object(
    'name', t.name,
    'year', t.year,
    'description', t.description,
    'images', coalesce((
      select json_agg(json_build_object(
        'url', 'trip-images/' || i.storage_path,
        'position', i.position) order by i.position)
      from public.trip_images i where i.trip_id = t.id), '[]'::json)
  ) end
  from public.trips t
  where t.public_id = p_public_id;
$$;

revoke all on function public.get_public_trip(text) from public;
grant execute on function public.get_public_trip(text) to anon, authenticated;
```
